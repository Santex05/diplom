# Материалы для защиты диплома AniHex

| Папка | Тема | Кто |
|-------|------|-----|
| `01-server/` | Серверная логика + админ API | Вы |
| `02-web/` | Веб-платформа (React) | Вы / фронт |
| `03-docker/` | Docker и деплой | Одногруппник |

В каждой папке:

| Файл | Назначение |
|------|------------|
| `diploma.html` | Текст ВКР (просмотр в браузере) |
| `diploma.docx` | **Тот же текст для Microsoft Word** |
| `presentation.html` | **Презентация — листать вниз** (не кликать) |
| `speech.md` | Речь по разделам + ответы жюри |

### Word (diploma.docx)

В каждой папке лежит готовый **`diploma.docx`** — конвертация из HTML с оформлением по методичке:

- Times New Roman **14**, интервал **1,5**
- Поля: слева **30 мм**, справа **15 мм**
- Абзацный отступ **1,25 см**
- Разрывы страниц по блокам (как в HTML)
- Нумерация с **3-й** страницы (введение), титул и содержание без номера

**Пересобрать после правок в HTML:**

```bash
python diploma-materials/shared/html_to_word.py
```

**В Word после открытия:**

1. Замените `[ФИО студента]`, `[руководитель]`, `[специальность]`.
2. Вставьте скриншоты вместо `[Вставьте скриншот: …]` в приложениях.
3. Обновите оглавление: выделите содержание → ПКМ → **Обновить поле** (если перевели пункты в автособираемое оглавление вручную).
4. Проверьте номера в содержании (Вставка → Номер страницы → при необходимости «Формат номеров» → начать с 3).
5. Сохраните финальный `.docx` или экспорт в PDF для сдачи.

## Презентация

1. Откройте `presentation.html` в **Chrome / Edge**.
2. **Прокручивайте вниз** — каждый блок «Раздел N» = один слайд (минимум **10** содержательных разделов в каждой теме).
3. Сверху — меню-якоря для быстрого перехода.
4. Текст доклада — только в **`speech.md`** (пронумерован под разделы презентации).
5. На слайдах: таблицы, SVG-диаграммы, места под скриншоты. Серые блоки — граница темы (что не входит в вашу работу).

| Папка | Разделов (слайдов) | О чём говорить | Чего не касаться |
|-------|-------------------|----------------|------------------|
| `01-server` | 11 + титул + «Спасибо» | Express, PostgreSQL, API, admin, ffmpeg, безопасность | React, nginx, Docker |
| `02-web` | 10 + титул + «Спасибо» | React, плеер, каталог, UX, кэш | SQL, Express, Docker |
| `03-docker` | 10 + титул + «Спасибо» | compose, образы, nginx, docker-data, VPS | Код API и компонентов UI |

**Скриншоты:** список в [SCREENSHOTS.md](SCREENSHOTS.md).  
Вставка: замените `<div class="screenshot-slot">…</div>` на `<img src="screenshots/имя.png" alt="…" />`.

**В PowerPoint:** копируйте секции по одной или печать в PDF (Ctrl+P) и импорт в PPT.

## Диплом (diploma.html / diploma.docx)

### Файлы

- **`diploma.docx`** — основной формат для правок и сдачи в Word.
- **`diploma.html`** — просмотр в браузере и повторная генерация docx.

### Страницы и нумерация (HTML)

- Текст разбит на блоки **`.doc-page`** (отдельные «листы» A4 на экране).
- **Титул и содержание** — без номера (`no-page-num`).
- **Введение и далее** — номер внизу по центру (3, 4, 5…).
- Для Word: открыть в браузере → копировать **по одному блоку `.doc-page`** или **Ctrl+P → PDF**.
- После PDF проставьте номера в **СОДЕРЖАНИИ**.

Повторная разбивка (если правили HTML):  
`python diploma-materials/shared/wrap-diploma-pages.py`

### Подписи таблиц и рисунков

В тексте уже есть формат **«Таблица 1 — …»**, **«Рисунок 1 — …»**.  
В приложениях — плейсхолдеры под скриншоты с подписями.

### Оформление по методичке

- Times New Roman **14**, интервал **1,5**
- Поля: левое **30 мм**, правое **15 мм**
- Абзац **1,25 см**
- Объём ДР **30–50 стр.** без приложений

Замените: `[ФИО студента]`, `[ФИО руководителя]`, `[специальность]`.
