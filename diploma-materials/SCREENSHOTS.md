# Скриншоты для презентаций и приложений диплома

Сохраняйте файлы в подпапки `01-server/screenshots/`, `02-web/screenshots/`, `03-docker/screenshots/`.

Чтобы вставить в HTML-презентацию, замените блок `.screenshot-slot` на:

```html
<img src="screenshots/02-home.png" alt="Главная страница" />
```
